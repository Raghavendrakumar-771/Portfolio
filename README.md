# Raghavendra Kumar Portfolio

An orange and black React portfolio website built from the resume content.

## Step-by-step setup

1. Open this project folder in a terminal.

   ```bash
   cd outputs/raghavendra-portfolio
   ```

2. Install dependencies.

   ```bash
   npm install
   ```

3. Start the development server.

   ```bash
   npm run dev
   ```

4. Open the local URL shown by Vite, usually:

   ```text
   http://localhost:5173
   ```

5. Build for deployment.

   ```bash
   npm run build
   ```

6. Preview the production build.

   ```bash
   npm run preview
   ```

## Customize links

Update the `links` object in `src/data.js` with your real LinkedIn, GitHub, project, and certificate URLs.

## Gesture interactions included

- Cursor spotlight follows pointer movement.
- Cards tilt softly on pointer movement.
- Project slider supports swipe gestures on touch devices.
- Sections reveal as they enter the viewport.
- Buttons and project cards have touch-friendly hover and active states.
